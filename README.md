# Cambria Automation Module (Patched)

Модуль автоматизации Cambria с исправлениями для автономной работы.

## Что исправлено:
1. **Эмуляция сервера лицензий**:
   - Патч `patch-impit.js` перехватывает запросы к офлайн-серверу лицензий (`77.239.111.213:3000`) в сетевом клиенте `impit` и возвращает мгновенный статус `OK`.
   - Запускается автоматически через `"postinstall": "node patch-impit.js"`.

2. **Адаптация Intercom Widget Loader**:
   - Исправлена несовместимость с новым форматом CDN-скриптов Intercom (внедрение метаданных `public_path:` для загрузки современного фрейма).

## Установка и запуск:
```bash
npm install
node index
```
